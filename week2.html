Review - HW 1

Let $n$ be a natural number. Show that the fraction \[ \frac{21n + 4}{14n + 3} \] is in simplest form.

Solution

A fraction $\frac{a}{b}$ is in simplest form if $\gcd(a, b) = 1$.

Thus, we need to show $\gcd(21n + 4, 14n + 3) = 1$ for all $n$. We can use the Euclidean algorithm:

\[ \begin{align*} \gcd(21n + 4, 14n + 3) & = \gcd(7n + 1, 14n + 3) \\ & = \gcd(7n + 1, 1) \\ & = 1. \end{align*} \]

Since this holds for all $n$, the fraction is in simplest form.

Number Bases

Our normal numbers are in base 10:

  • We use 10 different symbols for digits.
  • Each digit represents a power of 10.
  • $523 = 500 + 20 + 3 = 5 \cdot 10^2 + 2 \cdot 10^1 + 3 \cdot 10^0$.

There is nothing special about 10. What about base 2?

  • We use 2 different symbols, $0$ and $1$.
  • Each digit represents a power of 2.
  • $101_2 = 1 \cdot 2^2 + 0 \cdot 2^1 + 1 \cdot 2^0$

The subscript $2$ ($101_2$) indicates the base.

Number Bases

  1. Convert $101_2$ to base 10. $101_2 = 2^2 + 0 + 2^0 = \boxed{5}$.
  2. Convert $1101_2$ to base 4. $1101_2 = 13_{10} = \boxed{31_4}$.
  3. Convert $73$ to base 3. $73 = \boxed{2201_3}$.

We can use a special trick for number 2, since the bases $2$ and $4$ are both powers of $2$.

When going from base 10 to any other base, we can use a remainder trick.

Number Bases

General form for a number in base $b$:

\[ \overline{d_n d_{n-1} \dots d_1 d_0} = d_nb^n + d_{n-1}b^{n-1} + \dots + d_1b^1 + d_0 \] where $d_n$, $d_{n-1}$, $\dots$, $d_0$ are the digits of the number in base $b$.

Modular Arithmetic

Many times in number theory, we are more interested in remainders than the actual numbers.

If it is currently 4 o'clock, what time will it be in 100 hours? 104 o'clock = 8 o'clock.

Since the remainder of $104$ divided by $12$ is $8$, we write: \[ 104 \equiv 8 \pmod{12} \] (read "104 is congruent to 8 modulo 12").

Any numbers with the same remainder are considered "equivalent":

\[ 8 \equiv 5 \equiv 2 \equiv -1 \pmod{3}. \]

Modular Arithmetic

The formal definition is as follows:

Definition of Congruence
Given an integer $m \geq 1$, called a modulus (pl. moduli), two integers $a$ and $b$ are congruent modulo $m$ if there exists an integer $k$ such that \[ a = b + km. \] Congruence modulo $m$ is denoted by \[ a \equiv b \pmod{m}. \]

Properties of Congruence

Congruence satisfies all properties of an equivalence relation:

  • Reflexivity: $a \equiv a \pmod{m}$
  • Symmetry: $a \equiv b \pmod{m} \iff b \equiv a \pmod{m}$
  • Transitivity: $a \equiv b \pmod{m}$ and $b \equiv c \pmod{m} \implies a \equiv c \pmod{m}$

If $a \equiv b \pmod{m}$, then $a + k \equiv b + k \pmod{m}$ for all $k$.

Properties of Congruence

If $a_1 \equiv b_1 \pmod{m}$ and $a_2 \equiv b_2 \pmod{m}$:

  • $a_1 + a_2 \equiv b_1 + b_2 \pmod{m}$
  • $a_1 - a_2 \equiv b_1 - b_2 \pmod{m}$
  • $ka \equiv kb \pmod{m}$ for all $k$
  • $ka \equiv kb \pmod{km}$ for all $k$
  • $a_1 a_2 \equiv b_1 b_2 \pmod{m}$
  • $a^k \equiv b^k \pmod{m}$ for all non-negative $k$

Modular Inverse

Over the reals, we call $5$ and $\frac{1}{5}$ (multiplicative) inverses, since $5 \cdot \frac{1}{5} = 1$.

In modular arithmetic, we can also define inverses:

Definition of Modular Inverse
The modular inverse of $a$ modulo $m$ is an integer $a^{-1}$ such that \[ aa^{-1} \equiv 1 \pmod{m}. \]

Compute $3^{-1} \pmod{5}$ $3(2) = 6 \equiv 1 \pmod{5}$, so $3^{-1} \equiv 2 \pmod{5}$.

Compute $5^{-1} \pmod{7}$ $5(3) = 15 \equiv 1 \pmod{7}$, so $5^{-1} \equiv 3 \pmod{7}$.

How about $4^{-1} \pmod{6}$? $4$ has no inverse mod $6$.
